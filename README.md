Vice Cover Studio turns your own photos into GTA 6-style cover art: arrange one photo or several across the classic multi-panel poster layout, crop and position each panel, grade the whole cover with a Vice City sunset or neon look, stamp it with bold caption lettering, and export a share-ready PNG in 1080 x 1080, 1080 x 1350 or 1920 x 1080. It runs fully offline in a desktop browser from its own static files — your photos never leave your machine. All art, lettering and layout are original to this project.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser, drop in a photo, and export your cover.
